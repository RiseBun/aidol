# A’IDOL 本地预览与登记管理

## 启动
在本目录运行 `python3 server.py --port 8768`，访问 http://127.0.0.1:8768/ 。请勿用静态 http.server 替代，否则表单无法保存。

- 首页：全球品牌、OUR IDOL 名单预告、长期社区、品牌合作与发起团队。
- 上海首季：`/season-01.html`。
- 参赛意向：`/join.html`；合作意向：`/partner.html`。
- 管理后台：`/admin.html`。首次启动生成口令，见本机 `private/admin-password.txt`，不要上传或分享此文件。
- 数据：`private/intake.sqlite3`。后台可按类型筛选，更新跟进状态和备注。重启后登记数据仍保留，需重新登录。
- 测试：`python3 test_backend.py`，使用临时数据库，不写入真实登记。

## 本轮内容决策
品牌立足中国、面向全球；上海是首季起点。首季全国招募、上海线下三天两夜。个人和已有团队均可登记，个人入选后在活动前组队。想法与已有原型均可参加，披露赛前成果、记录赛期新增。

五阶段：招募选拔 → 名单揭晓 → 初舞台亮相 → 总决赛路演 → AI Idol 出道。全队先展示，专业评审选出主要决赛阵容；团队应援投票在全员成果展示后截止，剩余符合要求团队的最高票者获得 1 个额外席位。专业奖与人气荣誉分别呈现。团队专业奖看最终产品表现；个人奖项另设，细则待定。

多方向赛题、实体与仿真分组评审、部分提供设备与允许自带。出道支持为人物作品传播和后续项目支持，以落实资源为准。网站并行承接参赛与合作意向，当前不是正式报名。

## 保留待定
时间场地、规模、正式决赛名额、赛题与设备清单、费用食宿交通、个人奖细则、人气奖计票阶段与截止时间。团队真实姓名与可核验履历尚待补充，不编造。

## 发布范围
此版本为本机可用的动态预览，未部署至公网。`build.sh` 仅生成静态页面，不包含登记服务；正式上线需部署 Python 服务及持久化数据，并配置 HTTPS 与线上运营所需的数据管理方案。
